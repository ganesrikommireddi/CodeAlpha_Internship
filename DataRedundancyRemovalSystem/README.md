# CodeAlpha Data Redundancy Removal System

A simple Flask-based system that validates new records, detects duplicate email or phone numbers, and stores only unique records.

## Features
- Add records
- Email and phone validation
- Duplicate detection
- View stored records
- Delete records

## Run
```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
